## Summary

This release refreshes the Windows desktop installer and fixes the broken shortcut behavior seen in `v0.0.0`.

Highlights:

- fixes executable and shortcut naming for the Windows installer
- rebuilds the `nsis-web` installer as `0.0.1` to avoid stale Windows/browser cache from `0.0.0`
- keeps the downloaded setup file small while downloading the full app package during install
- improves desktop window behavior by removing forced maximize and remembering the previous window state
- adds a compact desktop layout for narrower windowed usage
